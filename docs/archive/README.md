# Archive

Historical documents kept for reference. They describe plans or states that
shipping has since moved past. Nothing here is authoritative — the live doc set
(`00`–`07`) plus `question-page-brief.md` is.

## Contents

**`2026-09-penpot-ui-workflow.md`** — the Penpot UI design workflow. Written when
the product was conceived as an in-person, shared-device deck game, with the
remote "a question a day" flow as a secondary extension. The shipped app kept
both modes but the remote loop became the product spine, so this document's
framing, ordering, and token table no longer match reality. Its token values
also mix light and dark palettes (e.g. light paper with a dark surface colour).

**`2026-09-penpot-build-checklist.md`** — a Penpot progress log tracking the
above workflow, phase by phase. Inherits the same token drift.

Both were archived rather than corrected on 2026-10-13: the screen-by-screen
comparison between them and the code found the product had deliberately moved on,
and rewriting them would have duplicated what the user-flow doc already says.
The in-person session flow they describe *was* correct, so it was folded into
`04-user-flows.md` when that doc was rewritten.
